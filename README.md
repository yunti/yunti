「云梯」取自两个典故——《逍遥游》的云，《墨子》公输的梯。
翼往远处想，梯往实处做。这也是我做企业 AI 的方式。

我做的是把大模型接进企业真正在跑的业务里。

落地过银行、医疗、水务、能源、金融。行业不同，卡点却常常一样：
Demo 三天能跑通，进生产要三个月。中间隔着的是数据怎么进来、
结果凭什么可信、失败怎么重来，以及一台连不上外网的机器怎么部署。

我的位置在业务方和工程之间：听得懂业务要什么，
也能把它拆成能上线、能维护的系统。不训模型，做的是让模型活下来的那一层。

> **EN** ｜ I help enterprises put LLMs into production — banking, healthcare, water utilities, energy,
> and finance. A demo takes three days; production takes three months. What's usually missing is data
> plumbing, verifiable output, failure recovery, and deployment onto networks without internet access.
> I don't train models; I build the layer that keeps them alive.

### 在做的事

多模态文档解析 · RAG 与知识库 · 智能外呼与语音交互 · MCP 与系统集成 · 中后台底座 · 浏览器自动化

展开说其中两项：

**多模态文档解析**
PaddleOCR PPStructureV3 做版面结构解析，多模态模型理解嵌入图像。
Celery 任务链与 chord 并发聚合，Redis Stream 推 WebSocket 回传实时进度。

**RAG 与知识库**
Milvus 向量检索 + 混合召回 + 语义重排，服务知识问答与文档检索场景。
